# Decoder-only Fundamentals Curriculum

## Release scope

This release adds a six-Part, fourteen-Chapter learning path for the existing decoder-only model experience. Parts 0-2 introduce text processing, tokenization, next-token language modeling, and numeric representations. Parts 3-5 reuse the existing GPT, Transformer Block, and Self-Attention routes and Guides rather than creating duplicate architecture pages.

The exact spine is:

1. Part 0: 자연어 처리란?, Token이란?, Vocabulary와 Token ID, Tokenization 방식
2. Part 1: 언어 모델이란?, 다음 Token 예측, 조건부 확률, Autoregressive Generation
3. Part 2: Token Embedding, Position Embedding, Hidden State
4. Part 3: GPT
5. Part 4: Transformer Block
6. Part 5: Self-Attention

Chapter succession is derived from validated Part and Chapter order. The product does not store successor foreign keys, add URL/history navigation, or create synthetic architecture routes.

## Interaction and rendering contract

- The Chapter table of contents is a non-modal disclosure with fourteen native buttons and exactly one visible `aria-current="page"` entry while expanded.
- Previous and next controls use destination names. The first Chapter omits previous; the final Chapter omits next.
- Progress exposes the current ordinal out of fourteen.
- Chapter activation and cross-route registration move focus to the validated destination without Worker mutation.
- At `1440x900`, Diagram and Guide use the binding 48/52 split within two percentage points. At `1024x768` and `390x844`, Diagram precedes Guide in a stacked layout.
- Every visible actionable owner is at least 44 by 44 CSS pixels, routes its center and four edge probes to itself, and participates in keyboard focus.
- Document and every visible local owner have zero effective horizontal overflow.
- Each conceptual Diagram exposes one named image, a semantic HTML fallback, and separate sibling controls.
- Trusted KaTeX output exposes one Chrome AX `math` semantic unit and accessible name per sampled formula boundary without nested duplicate math nodes.

## Technical boundaries

The curriculum is read-only with respect to model execution. It adds no Worker request, response, schema version, tokenizer implementation, tensor Visualization, heatmap, inspector, layer picker, slider, toggle, placeholder, or no-op control. Browser actions must keep Worker action delta and history action delta at zero.

Tokenizer examples are generated by Rust from the canonical UTF-8 byte tokenizer. Current model facts remain source-bound: learned token and absolute position embeddings, Pre-LN blocks, causal attention, exact GELU, tied LM head, accumulated-prefix generation, and no persistent generation KV cache.

Formula content comes only from the trusted static catalog. The five curriculum additions are next-token softmax, the three-token chain rule, the general sequence chain rule, embedding table shape `[Vocab,C]`, and hidden state shape `[T,C]`.

  --evidence .omo/evidence/curriculum/phase-08 \
