# Generated production Worker

Files in this directory are machine-generated by `scripts/build-worker-wasm.sh` from the locked `transformer-viz-worker` Rust binary, then consumed by Vite's explicit Worker entry. Do not edit generated JavaScript, TypeScript declarations, or WASM by hand.

Only this README and `.gitignore` are committed. Every production build regenerates these ignored artifacts with the pinned wasm-bindgen and workspace Binaryen tools.
